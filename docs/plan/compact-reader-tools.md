# 작은 읽기 도구와 보기 설정

2026-10-23 사용자 첨부 화면을 참고해 읽기 도구가 본문, 특히 가로 화면을 과도하게 가리는 문제를 우선 개선한다. 책장 UI/추가 기능은 이 작업 뒤 세부 요구를 논의해 별도 계획한다. 참고 이미지의 PDF 본문/표지는 저장소나 외부에 복사하지 않는다.

- 상단은 제목/뒤로·기존 방향/가로 잠금 아이콘을 유지하는 낮은 한 줄이다.
- 하단은 현재/목표 페이지와 기존 가로 슬라이더 한 줄, 작은 아이콘+짧은 이름의 버튼 한 줄로 정리한다. 페이지 이동 버튼은 제거한다. 북마크·일반 설정·현재 페이지 본문 읽기는 유지한다.
- 새 ‘보기 설정’은 PDF 위의 작은 하단 패널이다. 배경색(기존 자동/수동과 사용자 지정 포함), PDF 색반전, 밝기/시스템 밝기, 읽는 동안 화면 켜짐 유지를 모은다. 일반 설정의 기존 동작/내용은 유지한다.
- 기본 창은48dp 터치 영역을 유지하며 큰 글꼴/가로에서 내용 영역을 남긴다. 보기 설정은 높이를 제한하고 필요한 경우 내부만 스크롤한다. 배경색의 기존 상세 입력도 계속 접근할 수 있다.
- 저장/렌더 계층·PDF/원본·줌/위치/캐시·테마 정책은 바꾸지 않는다. 새 런타임 의존성 없이 플랫폼 View/Dialog를 사용한다. 보기 설정은 즉시 미리보기·기존 파일 저장을 사용하며 실패를 표시하고 입력/재시도를 유지한다.
- 관련 UI·보기 설정 저장/실패/복원·기존 일반 설정/배경·가로/큰 글꼴·슬라이더를 선별 검증한다. 기존 페이지 이동 버튼을 전제로 한 검사는 사용자가 선택한 슬라이더 경로로 갱신한다. 전체 기기/장시간·성능 검사는 반복하지 않는다.

개발용 앱만 사용하고 사용자 디자인/버전 변경은 보존한다. 현재 PR #32의 UI 수용 보완으로 진행하되 책장 설계 변경은 포함하지 않는다. 실제 결과는 SESSION/CHECKLIST와 별도 history에 기록한다.

## 구현·확인

구현과 관련 고유14개 기기 검사를 분할 보완해 완료했다. PC는 strict debug/계측·unsigned release·JVM73개/양 Lint·ktlint 통과다. 번호 미리보기의 폭 변화로 슬라이더가 취소되는 회귀를 문서별 고정 번호 폭으로 해결했다. 기존 배경/밝기/색반전 파일·원본/줌을 유지한다. 실제 명령·중간 실패/최종 범위는 [이번 이력](../history/2026-10-23-02-compact-reader-tools.md)을 따른다.

다음은 개발용 앱에서 작은 도구/보기 설정의 사용자 수용, 같은 PR #32의 최신 CI·리뷰 확인이다. 책장 디자인/세부 기능은 이 UI 확인 뒤 별도 논의하며 이번 작업의 완료로 포함하지 않는다.

사용자 수용 중 추가 조정: 본문 상·하단 버튼과 보기 설정 버튼/활성 행의 지속 배경을 제거하고 자동 체크/칩 테두리/스위치 상태로 구분한다. 연한 초록#DCEBD6·하늘#DEEFF7을 두 배경색 창에 추가한다. 시각 보완의 관련 검사2개·한계는 [후속 이력](../history/2026-10-23-03-plain-reader-actions.md)을 따른다.
