# PDF 색반전과 책장 관리

> 2026-10-29 상태: 합의한 구현/검증과 사용자 수용·병합은 완료했다. 현재 완료 범위·보류/제외는 [로드맵](roadmap.md), 실제 검증 한계는 [최신 정리](../history/2026-10-29-01-documentation-and-cleanup.md)를 따른다. 아래는 당시 계획/진행 기록이며 ‘다음·대기·미게시’ 문구나 포괄 검사 조건을 현재 미완료 필수 작업으로 재개하지 않는다. 모든 기기/API·전체 검사·공개 배포 완료를 뜻하지 않는다.


사용자 요청: PDF 페이지에만 적용하는 빠른 색반전, SAF 여러 파일 등록, 문서 일괄 선택·삭제·위치 변경과 사용자 책장.

## 구현 범위

- 읽기 도구의 빠른 색반전 토글. 전체 읽기 설정으로 재실행 보존. PDF 타일/미리보기/미준비 페이지에만 적용, 외부 배경 자동/수동 값과 원본은 유지. 줌/위치/캐시를 초기화하지 않음.
- 일반 추가는 여러 SAF URI를 중복 제거하여 한 번에 등록하고 목록에서 선택해 읽기. 실패 수/임시 권한을 안내. 재연결은 기존 한 파일 선택 유지.
- 전체/미분류/사용자 책장 필터. 책장 추가·이름 변경·삭제(문서는 미분류로 이동), 문서 다중 선택·책장 이동·등록 삭제. 위치 변경은 목록 위/아래 순서와 책장 간 이동으로 구현. 원본 파일 위치/내용은 변경하지 않음.
- 기존 읽기 기록/앵커/북마크를 보존하는 버전 마이그레이션. 등록 순서·책장·소속을 같은 AtomicFile 트랜잭션에 저장하며 위치 자동 저장과 분리해 관리 값 덮어쓰기를 방지.
- 새 런타임 의존성 없음. 모델/마이그레이션 단위 검사, 앱/계측 빌드·Lint·ktlint. 실제 기기와 픽셀·재실행 검증은 사용 가능한 환경에서 별도 판정.

## Windows 로컬 인계·컨벤션 확인

2026-10-23 사용자 요청으로 현재 체크아웃에 브랜치를 ff-only 인계하고 디자인/버전 변경을 보존한다. 책장 관리창·입력·목록은 기존 ReaderFormDialog/ReaderStyle/공유 어댑터를 재사용한다. 새 기능5개·직접 관련 배경6개·큰 글꼴1개를 선별 검증하며 전체96개/장시간·성능을 반복하지 않는다. 실제 SAF 선택/개인 사용 수용과 자동 합성 검사, 원격 CI·리뷰를 구분한다. [실제 결과와 한계](../history/2026-10-23-01-local-library-validation.md)를 따른다.
