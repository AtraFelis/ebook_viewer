# P3 — 20분 읽기 안정성 점검

> 2026-10-29 상태: 합의한 구현/검증과 사용자 수용·병합은 완료했다. 현재 완료 범위·보류/제외는 [로드맵](roadmap.md), 실제 검증 한계는 [최신 정리](../history/2026-10-29-01-documentation-and-cleanup.md)를 따른다. 아래는 당시 계획/진행 기록이며 ‘다음·대기·미게시’ 문구나 포괄 검사 조건을 현재 미완료 필수 작업으로 재개하지 않는다. 모든 기기/API·전체 검사·공개 배포 완료를 뜻하지 않는다.


2026-10-21 사용자 승인 범위. [첫 상태 안정화](p3-reading-stability.md)의 수정 앱을 변경하지 않고 현재 API 33 기기에서 진행한다. 긴 세션 검증을 첫 묶음의 과거 결과에 소급해 포함하지 않는다.

## 실행 전 고정한 절차와 판정

- 합성 100페이지 문서 두 개만 사용한다. 600×800/800×600 point 벡터 페이지를 섞고 실제 사용자 PDF·본문·파일명·URI·기기 식별자는 수집하지 않는다.
- 전용 `readingSoak` 계측은 기본 91개 검사에서 제외한다. 30초 간격 40회, 실제 경과 1,200초 이상으로 스크롤·핀치·잠금 전환을 반복한다. 문서 전환 10회, 홈 화면 왕복 20회, Activity 재생성 5회를 포함한다.
- 각 복귀/문서 재열기/재생성에서 페이지·문서 좌표·줌·배치를 비교하고 종료 뒤 저장 파일을 실제 재읽는다. 관측 시 타일 캐시 64MiB 이하, 백그라운드에서 0을 확인한다.
- 백그라운드의 동일 단계에서 매분 PSS·Java/native heap·열린 descriptor 수만 수집한다. 강제 GC는 하지 않는다. 준비/캐시 차이를 줄이기 위해 4~8분과 16~20분의 각 5개 중앙값을 비교한다.
- 사전 관측 예산: 후반 PSS 증가가 `max(32MiB, 초기 중앙값의 25%)` 이하, descriptor 증가 16개 이하. 이는 이 debug/계측 환경의 회귀 관찰 기준이며 일반적인 누수 부재 보장은 아니다. Java/native heap은 GC/할당자 영향을 함께 보기 위한 참고치다.
- 시스템 lowMemory 또는 thermal status 3 이상이면 중단한다. 의도적인 메모리 압박/OOM은 만들지 않는다. 계측 deadline 1,320초, PC deadline 1,380초로 제한한다. 불완료/실패를 통과로 세지 않는다.
- 앱 APK 설치 해시를 확인한 뒤 계측 APK만 교체한다. 진행 보고는 실행별 UUID로 이전 결과와 구분하고 로컬 ignored artifacts에 남긴다. 마지막에 합성 기록/파일 정리, 앱/계측 force-stop, ADB 종료를 확인한다.

## 한계와 완료

실제 20분 완료·상태 검증·메모리 관측 예산·정리 결과를 SESSION/CHECKLIST/[이력](../history/2026-10-21-09-p3-reading-soak.md)에 기록한다. 실제 스캔 문서의 복잡도·모든 PDF·다른 API/기기·하루 사용·실제 OOM/강제 프로세스 종료·새 렌더 속도/화질 벤치마크·아이콘·릴리스는 검증하지 않는다. 앱 런타임 의존성이나 저장 형식을 바꾸지 않는다. 결과에 오류가 있으면 근거에 맞는 최소 수정과 필요한 재검증을 별도로 판단한다.

## 재실행 명령

PowerShell에서 저장소 루트의 `. ./scripts/android-env.ps1` 후 strict `:app:assembleDebugAndroidTest :app:lintDebug ktlintCheck`로 PC 검증한다. 검증한 앱 APK가 기기에 설치된 상태에서 `./scripts/reading-soak.ps1 -Mode preflight` → `-Mode install-test` → `-Mode run` 순서로 진행한다. `run`은 한 번만 시작하고 실행 중에는 다른 터미널에서 `-Mode progress`로 읽기 전용 진행 확인만 한다. 종료 뒤 `-Mode collect`로 현재 실행의 JSON을 수집하며 이 읽기가 다시 시작한 ADB는 마지막 `-Mode stop`으로 종료한다. 강제 중단에도 `-Mode stop`을 실행한다. 결과/진행 파일은 ignored `local-artifacts/reading-soak-*`에만 남으며 이전 UUID의 결과를 새 실행의 성공으로 세지 않는다.
