# 최근 읽기 목록 삭제와 문서 등록 삭제 분리

2026-11-07. PR #37 사용자 병합4e707f9 기준, 현재 체크아웃의 codex/recent-history-removal에서 진행한다. 사용자 디자인/버전과 기존 상태 기록을 보존했다. 새 의존성은 없다.

최근 문서의 길게 누르기는 ‘최근 읽기 기록 삭제’ 전용 중앙 확인창으로 연결한다. 등록 PDF·앱 복사본·읽기 위치/줌/여백·북마크·책장 소속을 유지하고 최근 목록에서만 제외한다. 취소하면 그대로 남는다. 문서 자체 삭제는 기존 책장/전체 문서 경로를 유지한다. 파일 오류 복구의 문서 삭제도 기존 명시적 삭제 기능을 유지한다.

기록 v8은 카탈로그에 최근 목록에서 숨긴 URI 집합을 추가한다. v1~v7 읽기와 첫 v8 쓰기 전 before-v8 원본 바이트 백업을 유지하며 기존 백업/복사본 토큰을 바꾸지 않는다. 숨김 상태는 일반 위치 저장으로 되살아나지 않고 실제 읽기 성공 때만 해제한다. 목록 필터는 최대5개 제한 전에 적용한다. 재연결/등록 삭제 시 숨김 키도 카탈로그 관계와 일치시킨다.

단위 검사는 목록만 제외/데이터 불변·늦은 저장/재열기·재연결/실제 삭제·v8 보존/고정 v7 호환을 확인한다. 기기에서는 합성 문서로 메인의 주 카드/추가 행 길게 누르기·취소/확인·재생성/재열기와 복사본/북마크 보존·저장 실패·원본 백업을 검증한다. strict debug/계측/release 빌드·단위·양쪽 Lint·ktlint를 실행하고 실제 결과를 SESSION/CHECKLIST/history에 구분한다. 게시/리뷰/CI와 사용자 병합은 별도 확인한다.

추가 사용자 요구: 본문에서 여는 일반 설정과 그 세부창은 메인과 같은 기기 회전 정책을 따른다. 본문 고정 선택은 유지하고 설정을 닫으면 해당 방향/앵커·줌으로 복귀한다. 설정을 복원하는 Activity 생성 초반에도 이 정책을 적용해 본문 방향과 기기 방향 사이의 재생성 반복을 막는다. [ADR0024](../adr/0024-settings-system-orientation.md). 본문 위의 작은 보기 설정/방향 드롭다운은 기존 읽기 도구로 유지한다.

구현·로컬 검증·사용자 수용 완료. 단위100개/관련 API33 분할6개 성공, 최초 실패와 보완/미실행 범위는 [실행 이력](../history/2026-11-07-04-recent-history-and-settings-orientation.md)을 따른다. 원격 CI/리뷰·사용자 병합은 별도다.
