# P3 — 회전 위치·설정 창 전환의 제한된 조사

2026-10-22 사용자 승인: PR #27 병합 뒤 남은 간헐적 회전 위치 오차와 부모 설정/시작 포커스 실패를 먼저 조사한다. 현재 체크아웃을 origin/main 4822bc7에 ff-only 연결하고 codex/p3-rotation-focus-stability를 사용한다. 기존 상태 문서 변경과 사용자 docs/design.md 변경을 보존한다.

## 범위와 종료 기준

- 최초 실패 로그와 회전 저장/복원·스크롤·Activity/설정 창 수명을 대조한다. 기대값·허용 오차를 완화하거나 재시도로 실패를 숨기지 않는다.
- 원래 고배율 회전, 설정 적용/회전/부모 복귀, 번호 창 시작의 세 검사만 먼저 한 번 실행한다. 각 계측 90초/호스트 115초 한도, 합성 PDF만 사용한다. 재현되면 해당 경로의 최소 진단/수정과 필요한 관련 검사만 수행한다. 미재현이면 원인 미확정으로 남기며 무제한 반복하지 않는다.
- 필요하면 동일 세 검사 한 묶음만 추가해 실행 순서 영향을 구분한다. 전체91개·20분 검사·성능 측정은 반복하지 않는다. 기존 글꼴/설정을 복원하고 앱·계측·ADB를 종료한다. 연결·잠금 상태가 부적합하면 기기 검사는 시작하지 않는다.
- 변경이 생기면 strict 빌드·단위·Lint·ktlint 및 관련 기기 검사로 검증한다. 확인된 원인·수정·실패·미확인을 SESSION/CHECKLIST/history에 구분해 기록하고 완료한 묶음을 PR로 게시한다. 병합은 사용자가 한다.

## 아이콘 결정과 제외

사용자가 첨부한 파란 배경/흰 종이 아이콘을 최종안으로 선택했다. 원본을 docs/design-assets/selected-launcher-icon.png에 바이트 그대로 보존한다. 이번 조사는 런처 적용보다 먼저 진행하며 기존 사용자 디자인 문서는 수정하지 않는다. 아이콘 변형·런처 리소스 적용, 프로젝트 라이선스·버전·release 서명·배포 결정, 새 의존성은 이번 조사 범위에서 제외한다.

## 실제 결과

원래 세 검사 정순3개/실패0·65초, 실패 진단/시작 창 정리 보완 뒤 역순3개/실패0·60초였다. 앱 APK는 불변이며 같은 세 고유 검사를 총6회 실행했다. 전체91개나20분 검사를 반복하지 않았다. strict 빌드·단위·Lint·ktlint6초 통과(단위는 캐시 재사용), 글꼴/설정 복원·앱/계측/ADB 종료를 확인했다. 최초 실패는 이번에 재현되지 않아 근본 원인을 확인하지 못했다. 제한 조사와 진단 보완은 마치고 원인 해결은 미완료로 유지한다. 강제 시작 실패의 정리 경로 직접 주입은 미실행이다. 자세한 명령/실패/한계는 [실행 이력](../history/2026-10-22-02-rotation-focus-stability.md)을 따른다.
