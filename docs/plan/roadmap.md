# 개발 계획

[ADR 구성](../adr/0001-p0-toolchain-and-renderer.md) 승인 후 P0 앱/도구 초기화와 타일 프로토타입을 구현했습니다. 로컬 빌드·단위 테스트·Lint·ktlint 통과, API 33 기기 실행·계측 11개 통과. 현재 기기·합성 자료의 로컬 기술 검증은 완료했고 원격 CI는 main push 승인 대기입니다. 다른 API는 후속 미검증입니다. 실제 결과는 history에 기록합니다.

## P0 — 기술 검증

2026-10-16 사용자 결정: 개인용 현재 SM-N981N(API 33)을 P0 대상 기기로 한정한다. 다른 API/기기는 후속 미검증으로 명시하며 이번 완료 조건에서 제외한다. 현재 기기의 성능·안정성 결과는 계속 필요하다.

호환 버전과 Android 프로젝트 초기화, 빈 앱 빌드/실행, 엔진 기능·API·라이선스 매트릭스, 타일 렌더링/공통 줌 프로토타입을 준비합니다. 혼합 규격·스캔·벡터·대용량으로 측정합니다.

완료: ADR, 지원 범위, 재현 가능한 환경 명령, 실제 측정 보고서. 실기기가 없으면 성능 판정 보류.

## P1 — 핵심 MVP

SAF, 타일링·취소·캐시, 연속 좌표/제스처, 줌 유지, 간격·크기 모드, 회전·복원, 페이지 이동, 최근 문서, 북마크, 오류 UX.

완료: 핵심 수용 기준·기능 회귀와 실기기 성능 확인. 스크롤 품질 미달을 기능 확장으로 덮지 않음.

## P2 — 기본 기능 확장

검색·선택/복사·목차·암호화 지원, 테마·밝기·화면 유지, TalkBack/큰 글꼴. 엔진별 제한과 로컬 처리 검증.

## P3 — 안정화

기기/API·긴 세션·메모리 압박·접근성 회귀, CI와 라이선스/릴리스 체크리스트. 서명·스토어 게시 별도 승인. 주석·crop·EPUB는 이후 범위.

작업마다 목적, 범위, 수용 기준, 명령, 실제 결과를 기록합니다. P0 이전에 근거 없는 출시 일정을 정하지 않습니다.
