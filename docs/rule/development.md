# 개발 규칙

AGENTS.md가 기술/하드 제약 기준입니다.

- UI, 좌표/읽기 상태, 엔진, 캐시, 저장의 책임을 분리하고 불필요한 초기 멀티모듈을 피합니다.
- 엔진 수명/스레드 제약을 인터페이스에 명시합니다.
- 성능 변경은 동일 시나리오 전후 측정. 지연을 숨기려고 영구 저해상도를 사용하지 않습니다.
- 비밀번호 영구 저장이나 전체 저장소 권한은 기본 동작으로 도입하지 않습니다.
- 오류·취소·권한 소실·메모리 압박을 처리하고 실패를 무시하지 않습니다.
- 의존성 버전 고정과 정상 검증 메타데이터 갱신 절차를 사용합니다.
- 저장 형식/API 변경은 호환·마이그레이션을 검토합니다.
