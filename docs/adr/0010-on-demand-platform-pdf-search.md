# ADR 0010 — 기존 렌더러와 온디맨드 플랫폼 문서 검색

2026-10-18 (Asia/Seoul). 상태: **앱 구현·API 33 전체 회귀/검색 보완 검사 완료 / 개인 파일 수용 전**.

## 결정과 대안

기존 `PdfRenderer`의 픽셀 렌더링을 유지한다. 검색 요청 동안에만 같은 문서 FD를 복제해 `PdfRendererPreV` 텍스트 어댑터를 연다. 현재 API 33/S 확장 23에서 동작하며 `SDK_INT >= 30 && S 확장 >= 13`으로 진입을 제한한다. 확장 클래스는 별도 구현에 격리한다. 미지원 또는 클래스 연결 실패 시 검색 불가를 안내하고 기본 읽기를 유지한다. 다른 API/기기의 실행을 검증한 것은 아니다.

기본 렌더러를 PreV로 전면 교체하면 캐시/픽셀/성능 기준선까지 달라진다. 외부 PDF 엔진은 추가 라이브러리·네이티브 배포·라이선스/전이 의존성 비용이 있다. 현재 기능은 이미 승인된 플랫폼 구성과 설치 SDK 35로 구현할 수 있으므로 두 대안 모두 도입하지 않는다. 런타임 의존성, SDK·도구 버전, lockfile/verification-metadata 변경은 없다. [지원 조사와 공식 근거](0009-p2-platform-pdf-capabilities.md)를 따른다.

## 소유권과 스케줄링

- 기본 렌더러가 원본 FD를 소유하며 텍스트 어댑터는 복제 FD만 소유한다. 생성 실패에도 복제본을 닫고, 검색 종료/오류/취소/문서 종료에 텍스트 페이지와 렌더러를 해제한다. 하나의 worker에서 렌더와 텍스트 native 호출을 직렬 실행한다.
- 검색은 페이지 한 장씩 실행한 뒤 다음 장을 25ms 뒤에 예약해 가시 타일/메타데이터 작업에 worker를 양보한다. 한 페이지의 native 검색 자체는 중간 인터럽트할 수 없다. 문서/검색 세대로 오래된 실행과 UI 전달을 배제한다.
- 검색창 입력 변경·재검색·닫기, 문서 전환, 목록 복귀, Activity 정지 시 이전 검색을 취소한다. 검색창을 닫으면 마지막 선택 위치/강조는 읽기 화면에 남고 질의/목록은 저장하지 않는다. 새 문서를 열면 강조를 지운다.
- 결과는 최대 500건, 일치당 강조 사각형은 최대 32개다. 질의는 UTF-16 코드 단위 256자 상한이며 UI는 앞뒤 공백을 제거한다. 결과 상한에 도달하면 전체 건수처럼 표시하지 않고 검색어를 구체화하도록 안내한다.
- PDF 본문/인덱스/질의는 디스크·로그·외부 서비스에 저장하지 않는다. 플랫폼이 한 페이지에서 일시적으로 만드는 검색 결과/native 메모리까지 앱 결과 상한으로 제한된다고 주장하지 않는다. 실제 PSS와 최종 성능 회귀는 후속이다. 64MiB 공유 비트맵 캐시는 기존 그대로다.

## 검색·좌표 정책

플랫폼의 일반 문자열 검색을 사용한다. 한글/영문과 영문 대소문자 무시를 현재 기기의 합성 자료로 확인했다. 앱이 본문을 추출해 별도의 Unicode 정규화·줄바꿈 결합·정규식/퍼지 검색·OCR을 수행하지 않는다. 줄바꿈 경계/합자/분해형 문자의 세부 일치 정책은 플랫폼 결과를 따르며 합성 경계 수용은 후속 미검증으로 남긴다. 이미지 전용 페이지는 결과가 없고 OCR 미지원 가능성을 안내한다.

부분 결과/검색 진행 쪽수와 최종 결과를 구분한다. 이전/다음 결과로 이동할 때 현재 줌을 유지하고 결과가 가로 화면 밖인 경우 필요한 만큼만 이동한다. native 페이지 point 좌표에 기존 문서 배치 배율과 viewport 변환을 적용해 선택한 결과만 반투명 강조한다. 배경색/페이지 비트맵·캐시 내용은 변경하지 않는다. 혼합 크기와 회전된 텍스트의 native 결과 좌표를 검사했으며 PDF `/Rotate` 메타데이터 전 범위를 검증한 것으로 확대하지 않는다.

## 수용과 남은 일

검색 기기 계측 6개: 한글/영문/대소문자/없음, 혼합 크기·회전 텍스트/이미지 전용 페이지, 세대 취소와 기본 렌더 FD 보존, 500건 상한/문서 종료, 강조 픽셀/줌 유지, 실제 검색창 결과 이동/몰입형 복귀를 통과했다. 개인정보 대신 자체 생성 문서만 사용하며 테스트가 만든 기록만 제거한다.

전체 기존 기능 포함 47개를 통과했고 새 검색창 강조 초기화 보완 후 관련 검색 6개를 재통과했다. 두 APK/검사 범위는 실행 이력에 구분한다. 최종 통합 선명화/프레임/PSS·TalkBack/큰 글꼴·개인 PDF 검색 수용은 별도다. 텍스트 선택/복사는 아직 앱에 구현하지 않았다. 정확한 명령·실패 수정·최종 판정은 [검색 실행 이력](../history/2026-10-18-07-p2-document-search.md)에 기록한다. 이번 검색 어댑터 통합을 P2 전체 완료 또는 선명도 개선으로 세지 않는다.
