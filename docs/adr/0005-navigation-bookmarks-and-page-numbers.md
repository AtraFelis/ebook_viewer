# ADR 0005 — 페이지 이동·북마크·페이지 번호 표시

2026-10-17, P1. 승인된 플랫폼 Activity/View/AtomicFile을 사용하며 새 런타임 의존성 없음.

## 동작

중앙 탭 도구에 페이지 이동과 북마크를 추가한다. 페이지 입력은 표시 번호 1~전체 페이지 수이고 내부에서는 0 기반 인덱스로 변환한다. 입력이 잘못되면 기존 화면을 유지하며 대화상자에서 안내한다. 일반 이동은 선택한 페이지 시작을 화면 위에 배치한다. 북마크는 저장한 페이지 내부 y 앵커를 화면 중심에 복원한다. 둘 다 현재 줌을 유지하고, 현재 가로 위치가 대상 페이지의 유효 범위 밖일 때만 이동량을 제한한다. 페이지 스냅을 추가하지 않는다.

메타데이터를 점진 조사하는 동안 아직 준비되지 않은 페이지는 최신 요청 하나를 대기시킨다. 필요한 크기를 확보한 뒤 이동하며 UI 스레드에서 PDF/I/O를 실행하지 않는다. 화면 직접 조작/다른 이동/문서 전환 시 이전 대기 요청은 취소한다. 회전 중 대기 대상은 기존 viewport와 함께 Bundle로 보존한다.

페이지 번호 표시는 사용자가 설정한다. 기본 숨김이며, 켜면 읽기 화면 오른쪽 아래에 작은 현재/전체 번호를 표시한다. UI 위에 겹쳐 표시해 Canvas 크기·줌·앵커를 바꾸지 않는다. 숨겨도 페이지 이동/북마크 메뉴는 사용할 수 있다. 비열람 화면에는 번호를 표시하지 않는다. 사용자가 명시적으로 켠 번호는 기본 몰입형 UI 숨김의 예외다.

## 저장

- 페이지 번호 표시: ReaderSettingsRepository의 기존 I/O 큐, 별도 AtomicFile `reader-settings.bin.pages`, magic 0x45564e31/버전 1/0 또는 1. 파일 없음은 false, 유효하지 않은 버전/값은 오류이며 덮어쓰지 않는다. 기존 방향·배경색 파일은 변경하지 않는다.
- 북마크: Application 소유 단일 I/O 큐의 `bookmarks.bin`, magic 0x45564d31/버전 1. URI·0 기반 페이지·페이지 내부 y 비율만 저장한다. 문서/페이지별 하나를 유지하며 같은 페이지 추가는 앵커를 갱신한다. 최대 10,000개, 중복·비정상 좌표·미지원 버전은 거부한다. AtomicFile로 쓰기 중단을 복구하며 실패 시 기존 메모리/파일을 유지한다. 재선택 PDF를 정상적으로 연 뒤 북마크를 이전하고 읽기 기록을 재연결한다. 두 파일을 하나의 트랜잭션으로 취급하지 않으며 중단 시 재시도는 멱등적이다.
- 북마크 목록 항목을 누르면 이동하고 길게 누르면 삭제 확인을 연다. 삭제는 북마크만 제거하며 PDF를 삭제하지 않는다. 문서 재연결 시 기존 URI의 북마크를 새 URI로 이전하되 새 URI의 같은 페이지 항목을 우선한다.

## 범위·제약

북마크는 선택한 실제 PDF의 URI에 연결한다. 개발용 합성 문서 버튼에는 영구 URI가 없으므로 북마크 버튼은 비활성화하지만 페이지 이동은 가능하다. 변경된 PDF에서 사라진 페이지의 북마크는 임의로 지우지 않고 이동 실패를 안내하며 목록에서 삭제할 수 있다. 북마크의 과거 줌/가로 위치로 되돌리지 않는다.

파일은 앱 내부 로컬 메타데이터이며 네트워크/추출 텍스트/PDF 복제본을 저장하지 않는다. 앱 제거/데이터 삭제 시 지워진다. 다른 기기/API·실제 provider 재연결/재부팅의 수용과 스캔 PDF 선명도 지연 개선은 별도다. [명령·실제 결과](../history/2026-10-17-06-navigation-bookmarks.md)를 따른다.
