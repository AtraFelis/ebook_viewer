# ADR0024: 일반 설정은 기기 회전 정책 사용

2026-11-07. 상태: 사용자 추가 요구에 따른 결정·구현 및 관련 API33 검증 완료. 사용자 수용 완료. 원격 CI/리뷰·병합은 별도 확인.

ADR0021의 메인/본문 방향 분리에 이어, 일반 설정과 하위 설정창도 기기 정책(SCREEN_ORIENTATION_UNSPECIFIED)을 따른다. 저장한 본문 방향을 AUTO로 덮지 않는다. 부모 설정을 닫고 본문으로 돌아올 때만 본문 방향을 다시 적용한다. 작은 보기 설정/방향 드롭다운은 본문 위 읽기 도구라는 기존 정책을 유지한다.

Activity 재생성 초반에 설정 복원 상태를 먼저 읽어 본문 복원 때 임시로 고정 방향을 적용하지 않는다. 종료/메인 이동 중에는 방향을 되돌리지 않고 다음 화면이 정책을 정한다. 문서 앵커·줌과 설정 초안 복원은 유지한다. 새 런타임 의존성·설정 파일 버전 변경은 없다. [계획](../plan/recent-history-removal.md).
