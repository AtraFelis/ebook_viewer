# ADR 0019 — PDF 색반전과 책장 관리

상태: 사용자 기능 요청에 따라 구현. 새 런타임 의존성·엔진·스택 변경 없음. 기기 수용/성능 검증과 구분한다.

## 색반전

`PdfCanvasView`의 페이지 Paint에 RGB=255−RGB, alpha 유지 ColorMatrixColorFilter를 적용한다. 타일·저해상도/이전 타일·미준비 페이지의 흰 배경을 같은 paint로 그린다. Canvas의 외부 배경 drawColor, 원본 비트맵, 자동 배경색 분석 입력에는 필터를 적용하지 않는다. 외부 자동/수동 배경색은 기존 값 그대로다. 색반전은 파일 편집이나 앱 테마 변경이 아니다.

중앙 탭 읽기 도구의 `PDF 색반전 켜기/끄기` 버튼으로 접근한다. 전체 문서 공통 설정을 별도 AtomicFile `reader-settings.bin.inversion` v1에 저장한다. 로딩/저장 중 토글을 비활성화하고 실패하면 이전 값으로 복귀한다. 줌·앵커·렌더 요청·타일 캐시는 토글로 초기화하지 않는다.

## 여러 파일 등록

일반 SAF 선택에 EXTRA_ALLOW_MULTIPLE을 지정하고 ClipData와 data URI를 중복 제거한다. 선택한 책장에 신규 문서를 배치하고, 이미 등록한 URI의 위치/제목/책장/열기 시각은 유지한다. 여러 권을 추가한 후 목록에서 열 문서를 선택한다. 기존 재연결은 한 파일 선택으로 유지한다.

메타데이터 조회·영구 접근 권한 확보·기록 저장은 기존 library IO 큐에서 수행한다. 파일마다 등록 실패와 임시 권한을 집계하고, 목록 쓰기는 하나의 AtomicFile 작업이다. 등록 시 전체 PDF를 렌더하거나 복사하지 않으며 실제 읽기 가능/손상·암호화 판정은 문서를 열 때 기존 오류 경로에서 처리한다. 선택 중 대상 책장이 사라지면 신규 문서를 미분류에 둔다.

## 책장과 순서 저장

읽기 기록 v5는 기존 v4 문서 레코드 뒤에 책장(id/name), 전체 URI 순서, URI→책장 소속을 덧붙인다. 기존 v1~v4를 읽으며 첫 순서는 최근 열기 순서로 채운다. v5 이후 읽기 위치 갱신은 최신 catalog를 병합하므로 Activity의 오래된 ReadingRecord가 책장과 순서를 덮어쓰지 않는다. 모든 관리 값과 레코드를 같은 AtomicFile로 저장해 부분 삭제/이동을 방지한다. 읽기/쓰기에 문서 최대10,000·책장 최대1,000·이름100자 및 참조/중복/후행 데이터 검증을 둔다. 임의 사용자 이름 중복은 허용하고 ID로 구분한다.

목록은 전체/미분류/책장 필터와 사용자 순서를 제공한다. 기존 최근 읽기 시각은 이어 읽기 카드 선택에 계속 사용한다. 관리 모드에서 다중 선택·현재 목록 전체 선택/해제·일괄 책장 이동/등록 삭제·항목별 위/아래 이동을 제공한다. 필터 내 이동은 같은 필터의 이웃과 전체 순서상 위치를 교환한다. 관리 선택/필터는 Activity 재생성 상태에 보존하고, 필터 밖으로 옮긴 문서는 선택에서 제외한다.

책장 이름 변경은 ID와 소속을 유지한다. 책장 삭제는 그 안의 문서를 미분류로 옮긴다. 문서 등록 삭제는 기존 의미대로 목록/읽기 위치를 제거하며 원본 PDF는 삭제하지 않는다. 원본 파일 이동/삭제·여러 책장에 동시 소속하는 태그 방식은 이번 범위가 아니다. 북마크 별도 파일의 기존 삭제 정책은 변경하지 않는다.

v5를 쓴 뒤 구버전 앱은 해당 저장 형식을 읽을 수 없다. 미지원/손상 파일을 빈 목록으로 덮어쓰지 않는 기존 보호를 유지한다. 앱 데이터 삭제나 구버전 설치를 마이그레이션 절차로 안내하지 않는다.

## 검증

단위: v4→v5/기존 v1~v3 읽기, 책장/순서 round trip, 재등록 중복 방지, 읽기 저장과 이동 병합, 재연결, 필터 순서와 일괄 삭제, RGB/alpha 수학·설정 codec 오류.

기기 테스트는 PDF 내부/외부 실제 픽셀·줌/캐시/요청 불변, ClipData 중복/일괄 저장 재읽기·원본 보존, 관리 다중 선택/상태 복원 3개를 추가했다. 현재 클라우드에는 adb 연결 기기가 없어 실행 결과는 없다. 실제 provider 선택 화면·임시 권한/오류·자동 배경·재실행·큰 글꼴/가로 화면과 성능은 로컬에서 확인한다. 전체 P3 기기 검증의 과거 결과를 이번 코드 검증으로 확대하지 않는다.
