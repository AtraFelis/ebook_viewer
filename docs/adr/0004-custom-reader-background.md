# ADR 0004 — 페이지 외부 사용자 지정 배경색

2026-10-17. 사용자 요청과 위임에 따른 P1 범위 결정. 새 런타임 의존성 없음.

## 결정

P1은 사용자가 지정한 불투명 RGB 배경색을 앱 전체 읽기 설정으로 보존한다. 기본값은 기존 #444444이며 흰색/검정/회색/종이색 버튼, #RRGGBB 입력, 선택 색상 미리보기, 적용/취소를 제공한다. 입력은 6자리 RGB만 허용한다. UI 문자열은 리소스에 둔다. 읽기 중 중앙 탭→설정과 비열람 설정에서 같은 메뉴에 접근한다.

Canvas가 페이지 외부 배경을 지정 색으로 그리고 물리 cutout 안전 영역에도 같은 색을 사용한다. PDF 픽셀, 내부 여백, 페이지 좌표와 비트맵 캐시는 수정하지 않는다. 색 변경은 invalidate만 요청하고 타일/미리보기 렌더 요청을 추가하지 않는다.

기존 ReaderSettingsRepository의 Application 소유 I/O 큐에 저장 작업을 직렬화한다. 방향 설정 `reader-settings.bin`의 바이트/버전은 유지하고 별도 AtomicFile `reader-settings.bin.background`에 magic 0x45564231/버전 1/불투명 ARGB int를 저장한다. 파일 없음은 기본색, 손상/알 수 없는 버전은 오류로 처리하고 덮어쓰지 않는다. 쓰기 성공 후 화면에 반영한다. 계정/네트워크/새 저장 라이브러리는 필요하지 않다.

## 범위와 영향

사용자가 자동 모드를 P2로 미뤄도 되는지 위임했고, 예외/색 전환 검증 부담을 고려해 P1에서 제외했다. 자동 추출·대표색·대체색·스크롤 시 전환 억제는 로드맵 P2에서 검증한다. P1의 기본 회색은 자동 추출 결과가 아니다. 스크롤 선명도 개선도 [별도 P2 계획](../plan/p2-sharpness-recovery.md)으로 남긴다.

전체 앱 테마나 PDF 색상 반전, 내부 여백 자르기는 이번 기능이 아니다. 기존 플랫폼 View/AlertDialog/AtomicFile을 재사용해 스택/라이선스/lockfile을 바꾸지 않는다. 기존 방향 파일 마이그레이션도 필요하지 않다. 앱 데이터 삭제/제거 시 설정이 사라진다. 실제 테스트 결과와 미검증 범위는 [이력](../history/2026-10-17-05-custom-background.md)을 따른다.
