# ADR0023: 최근 읽기 목록과 문서 등록의 수명 분리

2026-11-07. 상태: 사용자 요청에 따른 결정·구현 및 관련 API33 검증 완료. 사용자 수용 완료. 원격 CI/리뷰·병합은 별도 확인.

메인의 최근 항목 길게 누르기에 문서 등록 제거를 공유하면 PDF 복사본과 책장 소속까지 사라진다. 최근 이력만 제거하는 사용자의 요구에 따라 이 진입점은 전용 확인/숨김 동작으로 분리한다. 전체 문서/책장과 파일 오류 복구의 명시적 문서 삭제는 유지한다.

카탈로그 v8에 숨긴 URI 집합을 저장한다. 읽기 위치를 null로 지우는 대안은 이어 읽기를 잃으므로 사용하지 않는다. 별도 파일 대안은 등록/재연결과 이중 저장 조정이 필요해 사용하지 않는다. 기존 URI/복사본/북마크·책장·앵커를 유지하고 v1~v7을 읽으며 첫 v8 쓰기 전 before-v8에 원본 바이트를 보존한다. 일반 위치 저장은 숨김을 보존하고 실제 열기 성공 이벤트만 숨김을 해제한다. [계획](../plan/recent-history-removal.md).
