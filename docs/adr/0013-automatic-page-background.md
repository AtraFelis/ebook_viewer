# ADR 0013 — 기존 미리보기에서 페이지 외부 자동 배경색

2026-10-19. 기존 PdfRenderer/View/AtomicFile과 JDK/Kotlin/SDK를 유지한다. 새 런타임 의존성 없음. [P2 범위](../plan/p2-scope-and-completion.md), [기존 수동 색상 ADR](0004-custom-reader-background.md)을 확장한다.

## 결정

자동 모드는 사용자 선택이다. 기본값과 v1 설정은 수동 및 기존 불투명 RGB를 유지한다. 동일 `.background` 파일의 v2는 기존 magic/버전/색 뒤에 모드 int(0 수동/1 자동)를 쓴다. v1을 읽고 v2로 저장하며 손상/알 수 없는 버전·모드/잔여 바이트는 거부한다. 읽기만으로 파일을 변경하지 않고 정상 저장 성공 뒤에 화면에 반영한다. 수동 색상은 자동 모드의 대체색으로도 보존한다.

대표 페이지는 화면 중심에 가장 가까운 세로 페이지 사각형이다. 인접 페이지 경계(간격의 중점) 24dp 안에서는 기존 대표 페이지를 유지하고, 새 후보가 120ms 유지되면 전환한다. 줌·균일 너비·간격에 맞춰 문서 좌표로 변환하며 줌/앵커를 바꾸지 않는다. 페이지별 결과는 현재 문서 최대 16개 색 정수로만 메모리에 보관한다. 문서 종료/교체 때 지우며 저장/로그/외부 전송하지 않는다.

캐시에 이미 있는 전체 페이지 미리보기(최대 512×512, ARGB_8888)를 읽기 전용으로 참조한다. 별도 낮은 우선순위 작업 스레드에서 2% 안쪽 가장자리 128점을 추출하며 새로운 PDF 렌더/페이지 열기/미리보기 확대/파일 I/O를 추가하지 않는다. 렌더 worker는 분석을 기다리지 않는다. 실행 1개+최신 대기 1개로 제한하고 이전 대기를 교체한다. 참조한 미리보기를 수정/recycle하지 않으며 UI 캐시도 게시된 픽셀을 수정/recycle하지 않는다. 캐시 퇴출 뒤에도 잠깐 참조할 수 있는 추가 픽셀 수명은 최대 2MiB다. 64MiB 캐시 상한은 그대로다.

불투명에 가까운 표본(alpha≥224) 32개 이상 중 상위 4bit RGB bin이 35% 이상이면 그 bin의 평균 RGB를 쓴다. 흰 종이/종이색·단색/어두운 페이지는 가장자리 우세 색을 반영하고, 여러 색의 사진·표본 부족/투명·사용 불가 bitmap의 실제 분석 결과는 지정 대체색이다. 2026-10-22 [ADR0018](0018-document-crop-and-reading-records-v4.md)에서 미준비 결과와 실패를 구분하도록 변경했다. 대표 페이지 결과를 기다리는 동안 직전 표시 색을 유지하며 첫 문서/reset/명시적 설정 변경만 지정 수동색으로 시작한다. 이는 페이지 전체의 의미/취향을 추정하는 기능이 아니며 흰 테두리가 있는 사진은 흰 테두리를 따른다.

문서 reset/설정 전환·메모리 trim/백그라운드·View detach에서 분석 큐와 handler를 취소하고 executor를 종료한다. 원래 bitmap은 해제하지 않는다. 세대 번호와 closed 검사로 이전 문서/모드의 늦은 결과를 무효화한다. 화면에는 색 정수만 전달하고 Canvas 바깥 배경/읽기 root에 적용한다. PDF 픽셀·페이지 내부 여백·타일 요청·캐시 해상도는 바꾸지 않는다.

## 근거·검증 경계

Context7 Android reference 조회와 [공식 Bitmap API](https://developer.android.com/reference/android/graphics/Bitmap)를 대조했다. getPixel의 sRGB ARGB 값, HARDWARE/recycled 접근 제한과 사용 중 recycle 금지를 확인했고 설치 API 35 android.jar의 javap 서명을 확인했다. Context7은 API 23/35 고정 스냅샷이 아니므로 현재 API 33 실행 검증과 구분한다. 새 SDK/외부 색상 추출 라이브러리를 도입하지 않는다.

자동/수동 전환·v1 호환·경계·예외/대체색·UI/재실행·PDF 픽셀/줌/요청 불변·종료/늦은 결과와 성능은 실제 실행 이력에 기록한다. 빌드만으로 미검증 사용성/성능이나 전체 P2 완료를 선언하지 않는다.
