# ADR 0022: 앱 내부 PDF 복사본

날짜: 2026-11-07. 상태: 사용자 요구에 따른 결정. 구현·관련 검증/평소 읽기 수용 완료, 원격 CI/리뷰와 병합은 별도 확인.

SAF 위치에 의존하면 외부 파일 이동/삭제·권한 취소로 읽기를 이어 갈 수 없다. 등록 시 앱 전용 영구 저장소로 복사하고 그 파일을 읽는다. 사용자는 문서 삭제 시 원본을 보존하고 앱 복사본·기록을 정리하도록 승인했다.

읽기 기록 v7은 기존 URI 식별자와 v6의 모든 필드를 유지하며 안전한 UUID 토큰만 추가한다. 절대 경로나 사용자 파일명을 복사본 경로로 받아들이지 않는다. v1~v6 호환과 첫 v7 변경 전 원본 메타데이터 백업을 유지한다. 외부 URI 자체를 내부 경로로 교체하는 대안은 북마크/소속 키의 불필요한 일괄 이전을 유발하므로 선택하지 않는다. 별도 매핑 저장소는 이중 커밋/복구가 필요하므로 선택하지 않는다.

복사는 백그라운드·취소 가능·버퍼 기반이며 이름이 확정된 파일만 기록에서 참조한다. 저장소 실패 때 원래 기록/원본을 보존한다. 표지와 본문 추출도 같은 복사본을 사용한다. 기존 자료는 다음 읽기 때 전환한다. 앱 데이터 삭제/제거 시 복사본이 사라지고, 앱 공간에 PDF 크기만큼 저장 용량이 필요하다. 외부 원본 변경은 등록한 스냅샷에 자동 반영하지 않는다.

새 라이브러리·계정·서버·권한은 도입하지 않는다. API/기기·성능 보장은 실제 검사 범위만 따른다. [실행 계획](../plan/managed-pdf-storage-and-recovery.md).

자동 잔여물 회수와 실패한 복사의 임시 파일 정리는 최선 노력이다. 삭제 실패가 카탈로그 사용을 막거나 기존 취소/IO 예외를 가리지 않도록 남겨 두고 다음 시작 때 재시도한다. 사용자가 요청한 명시적 문서 삭제는 실패를 계속 보고한다. [리뷰 보완 근거](../history/2026-11-07-03-managed-storage-review-fixes.md).
