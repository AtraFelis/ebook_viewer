# ADR 0016 — 문서별 가로 이동 잠금과 읽기 기록 v3

2026-10-21. 사용자의 가로 이동 잠금 개발 요청과 잠금 중 확대·축소 허용 조건을 반영한다. 기존 Kotlin/View/Canvas/AtomicFile만 사용하며 런타임 의존성/승인 스택 변경은 없다.

## 결정

문서별 페이지 크기·간격 설정에 기본 false인 `horizontalPanLocked`를 추가한다. 한 손가락 드래그의 X 성분과 가로 플링을 막고 Y 스크롤은 유지한다. 핀치의 기존 배율/중심 기준 확대·축소는 잠금과 독립적으로 허용한다. 두 손가락에서 하나로 바뀔 때 GestureDetector의 단일 포인터 기준을 다시 잡고 그 다중 포인터 스트림에서는 탭/잔여 플링을 발생시키지 않는다. 다음 새 한 손가락 제스처부터 정상 세로 플링을 허용한다.

첫 구현 수용 뒤 사용자 추가 지시로 잠금 중 두 손가락의 평행 가로·세로 드래그도 허용한다. 이동한 포인터 중심의 차이를 먼저 viewport에 반영한 뒤 새 중심에서 zoomAt을 수행해 이동 중 핀치의 문서 접촉점을 보존한다. 배율 변화가 시작되기 전에도 이동을 반영하며 GestureDetector의 다중 포인터 스크롤과 중복 적용하지 않는다. 같은 MOVE에서 확대가 처리됐으면 추가 constrain/타일 갱신을 반복하지 않는다. 포인터 추가/제거·취소 때 기준을 다시 잡고 하나만 남으면 그 위치에서 가로 잠금으로 돌아간다.

사용자 추가 지시에 따라 조작은 읽기 도구의 PDF 제목 오른쪽 잠금/해제 벡터 아이콘이다(22dp 그림/48dp 터치 영역). 중앙 탭으로 도구를 여닫는 기존 동작을 따르며 별도 설정 스위치를 만들지 않는다. 저장 중 비활성화/중복 방지, 성공한 상태 표시, 실패 시 기존 상태·오류 안내와 재시도 조작을 유지한다. 페이지 크기/간격 폼은 잠금 값을 그대로 보존한다.

잠금만 토글할 때 진행 중 플링을 멈추되 줌/좌표는 그대로 둔다. 페이지별 폭/전체 문서 폭을 바꾸거나 경계를 지날 때 자동 줌/재중앙 정렬/페이지 스냅을 추가하지 않는다. 기존 줌 한도·문서 경계 보정·회전/페이지 이동의 유효 앵커 규칙은 유지한다. 잠금 상태는 문서별로 이어 읽기에 복원하며 합성 데모는 세션용 설정만 사용한다.

## 저장과 복원

`reading-records.bin` magic은 유지하고 쓰기를 v3로 올린다. v2의 모드/간격 뒤에0/1 한 바이트를 추가한다. v1/v2 읽기는 유지하고 이전 버전의 잠금 값은 false다. 잘못된 잠금 바이트/절단/알 수 없는 버전은 거부한다. AtomicFile 저장 성공 뒤에만 메모리/실제 뷰를 반영하며 기존 초안/실패 재시도 경로를 사용한다. 이전 앱으로의 자동 역변환은 제공하지 않고 미지원 버전 덮어쓰기 금지 계약을 유지한다.

Activity Bundle과 설정 초안에도 잠금을 보존한다. 저장 중 재생성 시에는 기존 배치 키와 잠금 키를 함께 viewport에서 제외해 라이브러리 큐의 실제 저장 결과를 따르며 줌/내부 앵커는 보존한다. URI 재연결은 기존 문서 설정과 함께 잠금을 이전한다. 별도 파일/URI/원문 로그나 외부 서비스는 추가하지 않는다.

## 검증

v1/v2 읽기·v3 양 값 왕복/불량 바이트 보존, 혼합 폭 문서의 대각선 드래그/플링·핀치 확대/축소/두→한 전환/취소/토글 중 플링·해제, 실제 설정 저장/취소/실패 초안/재생성/재실행·문서 독립성을 검사한다. strict 앱/계측·단위/Lint/ktlint와 관련 개인 기기 회귀/사용자 수용을 실행 후 기록한다. 빌드를 실기기 성능으로 취급하거나 전체 성능 실험을 불필요하게 반복하지 않는다.
