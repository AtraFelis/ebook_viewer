# UI/UX 설계 준비와 Figma 파일 생성

2026-10-18 (Asia/Seoul).

## 요청·실행

사용자가 송채선 팀에 새 Figma 파일 생성과 저장소 docs/Markdown의 컨벤션 파악을 요청했다. Figma 파일 생성 스킬을 읽고 앞서 확인한 팀 선택을 사용해 Design 파일을 생성했다. 도구가 생성 성공과 [파일 URL](https://www.figma.com/design/wFQ8qOUx3YfMy8u0E3t7fM)을 반환했다. 파일 이름은 `Ebook Viewer — UI UX Design`이다. 디자인 요소 작성은 아직 하지 않았다.

`Get-Content`로 AGENTS → SESSION → CHECKLIST를 읽고 `git status --short`, `git branch --show-current`, `rg --files -g '*.md'`로 상태/문서를 확인했다. 시작 브랜치는 main이며 작업 트리는 깨끗했다. README/문서 목차, 제품 요구, 개발/Git 규칙, 로드맵/P2 계획, 구조, ADR 0001~0008, 개발 환경/Windows/전환/검증 문서와 관련 P1 UI·오류·완료 이력을 확인했다. 과거 도구/테스트 결과를 이번 실행 결과로 취급하지 않는다.

## 설계에 적용할 계약

- Android 휴대폰 우선. 현재 승인 UI는 플랫폼 Activity + View/Canvas이며 Compose 최종 선택은 미결이다.
- 로컬 SAF PDF, 계정/업로드 없는 기본 읽기. 개인 PDF/제목/URI를 디자인 서비스에 전송하지 않는다.
- 단일 열 연속 스크롤, 기본 페이지 간격 0, 페이지 스냅 없음. 회전/도구/이동/설정에서 사용자 줌과 내부 앵커를 보존한다.
- 전체 화면과 중앙 단일 탭 도구. 도구는 읽기 영역을 줄이지 않는 overlay이며 페이지 번호는 기본 숨김이다.
- 앱 공통 방향/외부 배경/번호 설정과 문서별 크기/간격을 구분한다. 외부 기본 배경 #444444는 앱 전체 테마나 PDF 반전이 아니다.
- 파일 오류는 원인과 재시도/재선택을 제공하고 기록을 보존한다. 목록/북마크 삭제는 원본 삭제가 아니다.
- P1 완료는 현재 개인 API 33 범위. 자동 배경색·선명도 개선·검색 등 후속 기능을 현재 제공 기능으로 표시하지 않는다.
- 새 의존성/스택 변경은 별도 승인. 문자열 리소스화, Kotlin 공식 스타일, 책임 분리, 비동기 렌더/I/O와 캐시 상한을 유지한다.

색상 토큰/서체 체계/간격 규칙/컴포넌트 라이브러리는 아직 확정되지 않았다. 먼저 플로우를 제안해 사용자 확인을 받고 디자인 시스템과 화면 설계로 진행한다.

## 검증·미결

Figma 생성 성공 응답 확인. 저장소 변경은 이력/SESSION/CHECKLIST뿐이다. 앱 코드/의존성 변경이 없어 앱 빌드·단위·기기 테스트는 미실행이다. 문서 공백 검사는 `git diff --check`로 수행한다. 커밋/push/PR/병합은 실행하지 않는다. 화면/토큰 작성과 플로우 승인은 후속이다.
