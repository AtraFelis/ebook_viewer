`git switch -c codex/p1-reading-library`로 현재 체크아웃에 작업 브랜치를 만들었다. 로컬 변경이 있으므로 불필요한 main pull/전환 없이 fetch 결과로 기반이 최신임을 확인했다. 새 worktree/reset/clean/강제 push 없음.

[직전 구현 검증](2026-10-17-01-p1-reading-library.md)의 동일 코드를 사용한다. strict debug 앱/계측 APK 빌드·단위 9개·Lint 오류/경고 0·ktlint, API 33 계측 15개, 다른 PID의 프로세스 복원 seed/verify 각 1개 통과 로그를 확인했다. 이번 PR 포장 단계는 Git/문서 변경뿐이므로 기기 테스트/성능 벤치마크를 반복하지 않는다. 실제 SAF provider별 권한 소실/재부팅·개인 PDF 수용·비탐색 임시 복사는 남은 범위로 PR 본문에 명시한다.
