선택·복사와 TalkBack 현재 페이지 본문 읽기는 별도 범위로 유지한다. 같은 플랫폼 native 텍스트 기능을 쓸 경우 해당 기능의 메모리·중단/취소·FD/프로세스 수명을 검증해야 한다. 검색 보류 때문에 안전 검증을 생략하거나 이 기능들도 자동으로 제외하지 않는다.
