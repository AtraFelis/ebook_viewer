# P1 MVP 요구사항 통합

2026-10-16 (Asia/Seoul). 작업 시작 HEAD `08011b3`, 현재 main 사용, 작업 트리 깨끗함 확인. 기존 사용자 변경 없음. 이번 변경은 계획/상태 문서만이며 로컬 미커밋·미푸시다.

## 사용자 요청과 정정

기존 P1 범위와 개인용 MVP 요구사항을 roadmap.md에 통합하도록 요청했다. 이후 “1번은 필요 없어. 지금 성능으로도 충분해”로 정정했다. 따라서 별도 렌더링·스크롤 성능 최적화는 필수에서 제외한다. 현재 동작을 유지하며 기능 추가에 따른 성능/줌/수명 회귀는 확인한다. P0의 성능 수치를 새 P1 기능 통과로 재사용하지 않는다.

## 문서 변경

- 로드맵: 최근 PDF/읽던 Ebook 목록·이어 읽기, 몰입형 전체 화면·중앙 탭 설정 접근, 가로/세로 고정, 자동/사용자 지정 외부 배경의 동작·구현 순서·수용 기준을 추가했다.
- 기존 P1의 SAF/접근 권한·오류·비탐색 provider, 간격/크기 모드, 줌/앵커 복원, 페이지 이동/북마크, 취소·캐시·자원 수명은 유지했다. 사용자 추가 필수 기능을 먼저 사용할 수 있게 하고 기존 범위를 완결한다.
- PDF 선택은 로컬 SAF 가져오기로 해석하며 서버 업로드/계정을 추가하지 않는다. 현재 Ebook 형식은 PDF 우선이고 EPUB는 기존 후속 범위다.
- 스마트 배경은 현재 페이지 가장자리의 로컬 표본을 우선 검토하고 안전한 대체색을 둔다. 세부 추출 알고리즘/저장 방식/추가 라이브러리 채택은 확정하지 않았다. 앱 성능 개선 작업을 새로 포함하지 않는다.
- 제품 UX 문서와 CHECKLIST/SESSION을 함께 갱신해 상시 도구 대신 전체 화면·탭 진입을 기준으로 맞췄다. 구현되지 않은 기능은 체크하지 않았다.

## 검증과 다음 행동

`git diff --check`와 문서 상대 링크 검사 통과. Git status/diff로 계획·제품·상태·이력 총5개 Markdown 파일만 변경됨을 확인했다. 앱 코드·빌드·의존성 변경이 없어 앱 빌드/기기 테스트·원격 CI는 재실행하지 않았다. 기존 P0 검사 결과는 그대로 유지한다. 다음 작업은 로드맵의 P1-1 파일/읽기 상태 기반과 목록·이어 읽기 구현이다. 새 런타임 의존성 또는 승인 스택 변경은 AGENTS의 구성안/승인 절차를 따른다.
