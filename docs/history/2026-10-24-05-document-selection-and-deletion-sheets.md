# 문서 선택 하단 도구·삭제 확인 시트

2026-10-24. 사용자의 두 참고 사진과 이어진 삭제 경고 변경 요청을 반영했다. 현재 체크아웃/기존 미커밋 작업과 사용자 디자인·버전·stash를 보존한다. 새 의존성/저장 형식·PDF 렌더링 변경은 없다.

## 변경

- 문서 선택 후 하단을 중앙의 아이콘+책장 이동 둥근 버튼과 빨간 휴지통 원형64dp 버튼으로 변경했다. 터치 영역/도형 크기를 분리하고 버튼 사이16dp, 얇은 경계/그림자로 구분한다. 목록과 별도 영역에 두어 마지막 문서를 덮지 않는다. 참고 사진의 다운로드 버튼은 요청 범위에 넣지 않았다.
- 평상시 정렬/보기 사이 선택 아이콘과 불필요한 리소스를 제거했다. 길게 누르기/더보기의 관리 진입, 선택 후 전체 선택/뒤로가기, 선택0개 하단 숨김은 유지한다. 전체 문서는 이동 없이 삭제만 중앙에 둔다.
- 문서 다중 삭제와 메인의 이어 읽기 기록 단일 삭제를 기존 LibraryWorkflow 하단 확인 시트로 연결했다. 책장 삭제는 편집에서 들어간 경우에도 하단 시트다. 뒤 배경 dim/내용 높이·취소/빨간 삭제 버튼을 통일했다. 문서의 앱 등록/읽기 기록/모든 책장 소속 제거와 원본 PDF 보존, 책장 관계만 제거하는 차이를 설명한다. 저장 성공 전에는 창을 닫지 않으며 실패 후 대상/재시도를 보존한다.
- 사용자가 ‘좋아’로 하단 버튼·선택 전 체크 제거·삭제 확인 시트를 수용한 뒤, 책장 이동 시트의 글자가 붙어 보인다는 미세 보완을 요청했다. 이동 시트에 한해 새 책장 행 위4/아래8dp, 책장 이름/문서 수 사이4dp, 행 상하8dp, 아래 토글 위8dp를 적용했다. 다른 화면/소속 처리 의미는 바꾸지 않았다.

## PC·기기 검증

`. ./scripts/android-env.ps1` 후 strict debug/계측/Lint/ktlint `--max-workers=2 --dependency-verification strict --console=plain`: 하단 도구14초·삭제 시트 포함14초 성공, Lint 오류/경고0. 최종 계측의 독립 측정 View visibility 검사 보완 뒤 계측/ktlint4초 성공. 변경 파일만 ktlint CLI1.5.0 --format을 명시 실행했다.

승인된/잠금 해제된 API33 기기에 개발용 `.p0`와 계측만 -r 설치했다. 고유3개 분할 검사 각각1개/실패0이다.

- `compactListKeepsTitlesAndScopeSpecificSelectionFooter`: 선택 전 체크/선택 위젯 없음, 길게 누르기·범위별 하단/0개 숨김·전체 선택/뒤로가기, 이동 버튼 콜백의 선택 집합과64dp 삭제/그림 크기·버튼 간격을 확인했다.
- `largeFontsAndLandscapeKeepDocumentGridUsable`:100/150/200% 글꼴 ×320×640/640×320의6개 측정 구성에서 선택된 하단 버튼끼리 겹치지 않고 목록을 덮지 않으며 목록 영역이 남는지 확인했다. 기기 시스템 글꼴/방향 설정을 바꾼 성능 검사는 아니다.
- `warningsUseBottomSheetsAndCancellationAndDeletionPreserveOriginals`: 별도 합성 파일/카탈로그로 단일 문서 삭제 취소·다중 경고 창 재구성/실제 삭제·원본3개 보존, 편집에서 책장 삭제 경고의 취소/복귀, 실제 책장 삭제 후 문서·다른 소속 보존을 확인했다. dim/아래 정렬도 검사했다.

합성 문서 View만 PNG로 가져와 하단 버튼을 시각 대조했고 앱/계측 force-stop·ADB 종료를 실행했다. 개인 PDF/읽기 기록/키를 외부나 PC로 추출하지 않았다.

마지막 이동 시트4~8dp 간격 보완은 표시만의 변경이라 앞선 동작/기기3개·단위83개를 반복하지 않는다. strict debug/Lint/ktlint·개발용 갱신 결과는 아래에 이어 기록한다. 기본96개/장시간·성능/OOM·다른 API·정식 서명/설치는 이번 결과가 아니다. commit/push/PR/CI·CodeRabbit은 미실행이다.

최종 간격 보완: strict `:app:assembleDebug :app:lintDebug ktlintCheck --max-workers=2 --dependency-verification strict --console=plain`10초 성공, Lint 오류/경고0. 개발용만 -r 설치 성공·앱/계측 force-stop·ADB kill-server 완료다. 사용자가 수용한 세 항목과 마지막 간격 보완의 미확인 상태는 구분한다.
