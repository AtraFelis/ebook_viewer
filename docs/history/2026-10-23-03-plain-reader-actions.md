# 본문 버튼 배경 제거·배경색 추가 — 2026-10-23

사용자 후속 피드백: 본문 도구 버튼과 보기 설정의 버튼/활성 행 배경을 없애고 연한 초록색·하늘색을 외부 배경색에 추가한다. 이 보완은 기존 PR #32/feat/pdf-inversion-and-bookshelves에서 진행하며 책장 UI는 여전히 별도 논의 대상이다.

## 변경

- 상단 뒤로/방향/가로 잠금과 하단 네 버튼의 지속 배경을 제거한다. 터치 영역/클릭/방향·잠금 상태 아이콘은 유지하고 누르는 동안의 ripple만 남긴다.
- 보기 설정 버튼과 색반전/화면 유지 행의 선택 배경을 없앤다. 자동 모드는 ‘자동 ✓’, 색상은 원형 칩/선택 테두리, 스위치는 본래 토글 상태로 구분한다. 실제 색을 보여 주는 칩과 입력칸은 유지한다.
- 연한 초록색#DCEBD6, 연한 하늘색#DEEFF7을 보기 설정과 기존 일반 배경색 창에 추가한다. 눈 건강 효능을 주장하지 않는다. 기존 직접 입력/자동 모드·저장 파일은 유지한다. 색상 줄은 가로 스크롤한다.
- 새 의존성·저장/렌더/제스처 변경은 없다. 사용자 디자인/gradle.properties와 stash20fbf558, 정식판/개인 키는 보존한다.
