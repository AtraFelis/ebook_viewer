## 사용자 결정과 영향

사용자가 개인용으로 목차와 비밀번호 PDF 지원이 필요하지 않다고 밝히고 목차 구현에 오래 걸릴지 물었다. 목차 화면 자체보다 현재 플랫폼에서 내장 계층형 outline을 읽을 경로가 없어 별도 엔진/보조 파서·라이선스/의존성 승인·목차/목적지 회귀가 필요하다고 설명했다. 실제 해당 엔진을 선정/통합하지 않은 상태에서 구체적인 시간/일수를 단정하지 않았다.

현재 P2 필수에서 두 기능을 제외했다. 앞선 ‘기존 P2 전체 포함’ 결정을 두 항목에 한해 변경하며 나머지 선명도 복구·자동 배경색·검색·선택/복사·테마/밝기/화면 유지·TalkBack/큰 글꼴은 유지한다. Figma 전면 디자인 적용도 계속 별도 단계다. 두 기능은 구현 통과로 체크하지 않으며 수요가 생기면 별도 범위를 재결정한다.

기존 사용자가 만든 북마크와 페이지 이동은 유지한다. 비밀번호 문서는 기존 지원 불가 안내/목록 복귀를 유지하고 암호 입력/저장/복호화·암호화 문서 이어 읽기 UI는 P2에 추가하지 않는다. 이미 생성·실행한 AES-128/256·목차 합성 자료/플랫폼 probe와 외부 후보 조사 사실은 보존한다. 그 실행을 앱 기능 구현 완료로 취급하지 않는다.
