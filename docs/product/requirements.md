# 제품 기능과 범위 — 개인용 PDF 뷰어

갱신: 2026-10-29. 현재 구현과 사용자 결정의 요약이다. 상세 결정은 AGENTS/ADR, 실제 검증 범위는 SESSION/history를 따른다.

## 읽기

PDF를 단일 열의 긴 문서로 읽는다. 페이지 경계에서 사용자 배율을 초기화하거나 페이지 스냅을 추가하지 않는다. 원본 크기/페이지 너비 통일과 간격을 문서별로 선택하고, 혼합 크기는 중앙 정렬한다. 회전·백그라운드 복귀·이어 읽기 때 페이지 내부 원본 앵커와 줌·유효 가로 위치를 복원한다.

핀치 초점 아래 문서 위치를 유지한다. 줌 허용 범위는 0.1~32 px/문서 point이고, 새 핀치의 축소 하한은 짧은 화면 변 너비 맞춤 배율의 75%다. 기존 작은 배율은 회전/복원 때문에 강제로 올리지 않는다. 가로 잠금은 한 손가락 가로 드래그를 막으며 두 손가락 이동/확대·축소는 허용한다.

원본 PDF 내부 여백과 앱 페이지 간격은 구분한다. 문서 공통 자르기는 원본 각 변의 0~45%를 미리보며 조정하고 적용/취소한다. 파일 자체와 본문 추출은 수정하지 않는다. 줌/북마크/이어 읽기의 저장 좌표는 원본 기준이다.

## 화면과 설정

- 평상시 콘텐츠 전체 화면, 중앙 탭으로 낮은 상단 도구와 페이지 슬라이더/작은 버튼을 표시한다. 별도 페이지 이동 버튼은 제거했고 슬라이더·북마크를 사용한다.
- 제목 옆 방향 아이콘은 다섯 모드 드롭다운, 가로 잠금은 별도 아이콘이다. 방향을 선택해도 창을 유지해 다시 선택할 수 있다. 일반 설정의 세부 창은 뒤로/닫기/적용 후 상위 설정으로 복귀한다.
- 보기 설정은 자동/수동 외부 배경색·PDF 색반전·밝기·읽기 중 화면 유지를 모은다. 자동 배경색 계산 대기 중에는 직전 색을 유지한다. 수동 프리셋은 흰색/검정/회색/종이색·연한 초록/하늘색과 임의 RGB 입력을 지원한다. 자동 선택은 회색/파란 글자로 구분한다.
- 색반전은 PDF 화면에만 적용하고 외부 배경색·원본 파일은 유지한다. 일반 설정에는 테마·번호 표시·문서 크기/간격·여백 등이 있다. 숫자 입력은 키패드로 조정한다.
- 번호는 기본 숨김이며 켜면 배경 없는 하단 중앙 표시와 대비 처리로 읽기 영역을 보존한다. 읽기 도구 버튼은 지속 배경 없이 아이콘/짧은 글자를 사용한다.
- 설정 저장 실패는 입력을 보존하고 오류/재시도를 제공한다. 지원 플랫폼에서는 현재 페이지 본문을 요청별 격리 프로세스로 읽는다. 큰 글꼴/일반 터치 사용은 유지한다.

## 문서와 책장

SAF에서 PDF 여러 개를 등록한다. 메인은 제목·설정·이어 읽기·PDF 추가를 유지하고 아래에 책장 격자를 표시한다. 미분류는 내용이 있을 때만 가상 책장으로 나타난다. 책장 표지는 묶인 최대 3개와 이름/문서 수/실제 최근 읽음/더보기로 구성한다. API 23~29나 표지 실패는 기본 문서 그림을 쓴다.

문서는 표지 격자 기본/목록 전환과 이름순·최근 읽은 순을 제공한다. 책장은 사용자 지정·이름순이며 편집의 삭제/순서 탭과 드래그 초안·저장, 편집 안의 추가를 제공한다. 일반 도구는 투명 아이콘+짧은 이름, 뒤로/설정/삭제 등 익숙한 동작은 아이콘만 사용한다.

같은 PDF는 여러 책장에 소속될 수 있고 원본/읽기 위치/북마크를 공유한다. 길게 눌러 선택하면 전체 선택을 제공하고 선택한 항목이 있을 때만 하단 동작이 나타난다. 전체 문서는 삭제만, 책장/미분류는 이동·삭제다. 이동은 한 목적지를 고르고 실제 출발 책장에 ‘이 책장에도 남겨두기’를 선택한다. 미분류에는 출발 관계가 없다. 책장 문서 추가는 이미 등록한 PDF 선택이다.

이동/더보기는 뒤 화면을 어둡게 하는 하단 시트다. 삭제 확인은 중앙의 둥근 창과 테두리 취소/빨간 삭제 버튼이다. 문서 삭제는 앱 등록·읽기 기록/소속을 제거하며 원본 PDF는 보존한다. 책장 삭제는 그 책장/관계만 지우고 문서 등록과 다른 책장 소속을 유지한다.

## 완료 범위와 후속

현재 개인 API 33 기기·합성 자료와 사용자 수용 범위의 기능을 완료했다. 다른 API/기기·실제 OOM·모든 PDF의 무지연은 검증하지 않았다. 선명화는 기존 PdfRenderer 안에서 개선했으며 원본 해상도/DPI·압축별 지연 원인은 확정하지 않았다.

검색·선택/복사 UI는 후속 보류, 목차·비밀번호 PDF 읽기는 필수 제외다. OCR·EPUB·강조/주석·동기화·원본 파일 이동/삭제·중첩 책장/사용자 표지는 미구현 후속이다. TalkBack 전용 추가 작업은 사용자 결정으로 제외하고 과거 구현/검증만 보존한다. 코드 LICENSE와 공개/스토어 배포도 별도 결정 사항이다.
