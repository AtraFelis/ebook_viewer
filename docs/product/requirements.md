# 제품 기획 — PDF 중심 Android 뷰어

## 목표와 핵심 요구

PDF 전체가 하나의 긴 문서처럼 느껴지는 단일 열 세로 스크롤이 최우선입니다. Android 휴대폰 우선, 태블릿은 후속 검증합니다.

1. 앱이 넣는 페이지 간격은 기본 0, 사용자 설정으로 조절. 구분선·그림자도 끌 수 있음. 서로 다른 크기/비율 지원.
2. 가로 화면에서도 전체/너비 맞춤을 강제하지 않고 사용자가 원하는 배율과 가로 위치로 읽음.
3. 페이지 경계를 넘어도 문서 전체의 줌과 가로 위치 유지. 회전 시 읽던 위치와 사용자 줌 유지.
4. 페이지 사이 정지·스냅 없이 플링/드래그 연결. 문서 시작/끝에서만 범위 제한.

앱 페이지 간격과 원본 PDF 내부 흰 여백은 별개입니다. 자동 여백 자르기는 후속 기능입니다. '규격 없이 붙음'은 원본 크기 유지/페이지 너비 통일 두 모드로 해석하며 혼합 너비는 기본 중앙 정렬입니다. 사용 예시가 제공되면 해석을 보완합니다.

## UX

읽기 중에는 콘텐츠 중심의 전체 화면을 기본으로 하고 앱 도구·PDF 열기 버튼·상시 상태 문구가 영역을 차지하지 않게 합니다. 중앙 단일 탭으로 도구와 설정을 표시/숨깁니다. 도구를 표시할 때 뒤로·파일명·더보기, 페이지 표시/이동·북마크를 제공하며 검색은 해당 기능을 구현한 단계에서 추가합니다. 비열람 화면에도 PDF 열기·최근/읽던 목록·설정 진입을 제공합니다.

P1 설정은 가로/세로 고정·자동 회전, 페이지 간격·크기 모드, 페이지 외부의 사용자 지정 배경색을 포함합니다. 미설정 기본색은 중립 회색(#444444)이며 자동 배경색 추출은 2026-10-17 사용자 범위 조정으로 P2에서 구현합니다. PDF 자체의 색과 내부 여백은 바꾸지 않습니다. 방향/배경 설정은 재실행 후에도 유지하며 화면 변경이 줌·읽기 앵커를 초기화하지 않게 합니다. 밝기·화면 켜짐 등은 후속 확장입니다.

핀치는 초점 아래 문서 위치를 유지합니다. 확대 시 두 축 이동을 허용하고 세로 드래그/플링을 연결합니다. 축 잠금은 후속 검토입니다. 페이지·북마크 이동은 줌과 유효 범위 안의 가로 위치를 유지합니다. 최초 열기만 너비 맞춤을 기본으로 하고 이후 재맞춤은 사용자가 명시적으로 실행합니다.

2026-10-17 확대/축소 조정: 최대 배율은 8에서 32 screen px/PDF point로 높여 기존 한도보다 4배 더 확대합니다. 핀치 축소 하한은 문서의 최대 페이지 너비를 화면의 짧은 변에 맞춘 배율의 75%입니다(절대 허용 범위 0.1~32). 이 하한은 새 핀치에만 적용하며 페이지 이동·회전·기록 복원 때문에 기존 줌을 올리지 않습니다. 이전에 더 작게 저장한 배율도 그대로 복원하고, 그 상태에서 축소를 막되 확대는 점진적으로 허용합니다.

## 범위

| 단계 | 기능 |
| --- | --- |
| MVP | SAF PDF 열기, 연속 스크롤, 핀치, 간격/크기 모드, 회전, 페이지 표시·이동, 읽기 위치/줌 복원, 최근 문서, 북마크, 오류/빈 상태 |
| 기본 확장 | 검색/결과 이동, 선택·복사, 목차, 암호화 PDF, 테마·밝기·화면 유지, 접근성 |
| 후속 | 강조·주석/내보내기, crop, 축 잠금, 읽기 방향, EPUB, 동기화 |

검색·선택·암호화는 엔진/API 지원 매트릭스로 검증합니다. 스캔 문서 OCR은 별도 범위입니다. 배경색 변경과 PDF 색상 반전은 구분합니다.

2026-10-16 P1 우선순위: 최근 읽은 PDF/읽던 Ebook 목록, 마지막 페이지 내부 위치·줌으로 이어 읽기, 방향 고정, 사용자 지정 배경, 몰입형 전체 화면과 읽기 중 설정 접근을 우선합니다. Ebook은 현재 PDF 우선 범위이며 EPUB는 후속입니다. 사용자는 현재 성능을 수용했으므로 별도 렌더링/스크롤 최적화는 P1 필수에서 제외하고 기능 추가에 따른 회귀만 확인합니다. 상세 순서와 수용 기준은 [P1 로드맵](../plan/roadmap.md)을 따릅니다.

## 수용 기준

- 간격 0에서 앱 추가 공백/겹침이 없고 혼합 크기 레이아웃 안정.
- 가로 화면 임의 배율에서 20페이지 왕복 후 배율 유지, 경계 정지 없음.
- 회전·백그라운드·프로세스 재생성 뒤 동일 페이지/내부 앵커와 줌 복원.
- 간격/크기 모드 변경 시 현재 내용이 앵커에 남음.
- 대용량에서도 전체 고해상도 선로딩 없이 제한된 메모리로 읽기.
- 부드러움은 실제 기기 프레임 측정으로 평가. 무조건 무지연을 보장하지 않음.
