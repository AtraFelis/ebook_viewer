# 검증 전략

갱신: 2026-10-29. 변경 위험에 맞춰 단위/빌드/Lint·기기/성능을 선택한다. 문서/캐시 정리에는 앱·장시간 검사를 반복하지 않는다. 실행하지 않은 검사와 과거 결과 재사용을 새 통과로 보고하지 않는다.

현재 `scripts/device-smoke.ps1`의 기본 기대 수는 96개다. 마지막 앱 변경에서 단위 84개(실패/오류/건너뜀 0), strict debug/계측·Lint 0/0·ktlint/unsigned release와 API 33 관련 검사만 실행했고 최종 기본 96개 전체는 미실행이다. [리뷰 보완](../history/2026-10-24-08-bookshelf-review-fixes.md), [마지막 API 분기 검사](../history/2026-10-24-09-cover-test-api-guards.md)의 실행 범위를 따른다.

P3 당시 기본 91개는 최초 전체 중단 후 분할 보완했다. 후속 코드/표시 수정 뒤 관련 검사를 추가했으며 단일 최종 전체 성공으로 합산하지 않는다. P2/P3의 성능·10분/20분 측정도 당시 앱/자료에만 적용한다. 실제 OOM/다른 API 기기·임의 PDF 안전성을 보장하지 않는다. 현재 개인 API 33가 완료 대상이고 TalkBack 전용 후속/수동 검증은 제외하며 큰 글꼴·일반 터치·본문 읽기는 유지한다.

기기 실행/종료와 개별 메서드 선택은 [배포 준비](../release-preparation.md), 합성 자료와 측정은 testing의 전용 절차를 따른다. 과거 실패/미완료도 원본 로그와 함께 보존한다. 아래 기능/성능 항목은 변경 시 확인 기준이며 전부 최신 APK에서 실행했다는 뜻이 아니다.

## 성능 초기 목표

2026-10-16 사용자 결정에 따라 이번 P0 판정 기기는 개인용 SM-N981N(API 33)으로 한정한다. 아래 기준의 다른 대표 기기/API 검증은 후속이다.

대표 중급 실기기, release/profileable, 60Hz, 로컬 PDF 기준. 기기·OS·메모리·주사율·SHA를 기록합니다.

- warm 연속 플링/핀치 프레임 p95 ≤ 16.7ms, p99 ≤ 33.3ms.
- 30초 시나리오의 50ms 초과 프레임과 jank 비율도 기록. 90/120Hz는 해당 예산으로 별도 평가.
- 일반 PDF 최초 유효 문서 화면 ≤ 2초 잠정 목표. cold/warm·provider·파일 크기 명시.
- 앱 소유 렌더 캐시 초기 상한 목표 64MiB 이하. 총 PSS/Java/native/graphics는 별도 측정 후 P0 예산 확정.
- 10분 이상 왕복 읽기에서 지속 메모리 증가/OOM/핸들 누수 확인.

Macrobenchmark/Perfetto/FrameMetrics 중 지원 도구 선택. 동일 조건 3회 이상 측정하고 에뮬레이터로 실기기 성능을 대체하지 않습니다. 목표 변경 근거는 history에 남깁니다.
