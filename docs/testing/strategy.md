# 검증 전략

현재 단위 테스트 22개와 API 33 기본 전체 계측 41개가 통과했습니다([최신 수명/캐시 검증](../history/2026-10-17-10-reader-lifecycle.md)). 별도 seed/force-stop/verify는 기본 41개와 구분합니다. 메모리 알림 주입/실제 HOME 복귀를 실제 시스템 고갈/OOM·재부팅 검증으로 취급하지 않습니다. 디버그 기능 검증과 릴리스 성능 판정은 구분하며 실제 수치는 history에 기록합니다. 아래 모든 성능 목표/다른 기기 범위를 통과한 것은 아닙니다. P1은 사용자가 현재 성능을 수용했으므로 별도 성능 최적화를 필수로 추가하지 않습니다.

## 기능

| 시나리오 | 기대 |
| --- | --- |
| 혼합 크기/회전, 간격 0 | 겹침/앱 공백 없음, 원본 내부 여백 유지 |
| 간격/크기 모드 변경 | 내부 앵커 유지 |
| 가로 확대 20페이지 왕복 | 줌/유효 가로 위치 유지, 스냅 없음 |
| 핀치 경계 통과/포인터 변경 | 초점 연속성, 플링 취소 |
| 회전/백그라운드/프로세스 재생성 | 앵커·줌 복원 |
| 페이지/북마크/검색 이동 | 목적 위치 표시, 줌 유지 |
| 손상/암호화/권한 소실/빈 문서 | 지원 범위에 맞는 오류, 무한 로딩/충돌 없음 |
| 빠른 반전/문서 전환 | 과거 타일 오표시·자원 누수 없음 |

좌표·누적 위치·가시 범위·복원·캐시 퇴거는 단위 테스트, 제스처/재생성은 계측 테스트, 부드러움은 프레임 측정으로 검증합니다.

## 성능 초기 목표

2026-10-16 사용자 결정에 따라 이번 P0 판정 기기는 개인용 SM-N981N(API 33)으로 한정한다. 아래 기준의 다른 대표 기기/API 검증은 후속이다.

대표 중급 실기기, release/profileable, 60Hz, 로컬 PDF 기준. 기기·OS·메모리·주사율·SHA를 기록합니다.

- warm 연속 플링/핀치 프레임 p95 ≤ 16.7ms, p99 ≤ 33.3ms.
- 30초 시나리오의 50ms 초과 프레임과 jank 비율도 기록. 90/120Hz는 해당 예산으로 별도 평가.
- 일반 PDF 최초 유효 문서 화면 ≤ 2초 잠정 목표. cold/warm·provider·파일 크기 명시.
- 앱 소유 렌더 캐시 초기 상한 목표 64MiB 이하. 총 PSS/Java/native/graphics는 별도 측정 후 P0 예산 확정.
- 10분 이상 왕복 읽기에서 지속 메모리 증가/OOM/핸들 누수 확인.

Macrobenchmark/Perfetto/FrameMetrics 중 지원 도구 선택. 동일 조건 3회 이상 측정하고 에뮬레이터로 실기기 성능을 대체하지 않습니다. 목표 변경 근거는 history에 남깁니다.
